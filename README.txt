BOXIUM — BIO SITE

Как запустить:
1. Распакуй архив.
2. Открой index.html в браузере.

Как опубликовать:
- Загрузи содержимое папки boxium_bio в GitHub-репозиторий.
- Для GitHub Pages выбери Settings → Pages → Deploy from a branch → main / root.
